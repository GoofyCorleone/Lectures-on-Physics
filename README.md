# Lectures on Physics

This repository contains a collection of physics lecture notes that I have written in **LaTeX** over the years. Each set of notes is accompanied by original figures created with **Inkscape**, available in both PDF (for direct inclusion in the documents) and SVG (editable) formats.

## Included courses

- ✅ **Lectures on Optics** (complete)
- ✅ **Lectures on General Relativity** (complete)
- ✅ **Lectures on Quantum Optics** (complete)
- ⏳ **Lectures on Special Relativity** (incomplete)
- ⏳ **Lectures on Statistical Physics** (incomplete)
- ⏳ **Lectures on Plasma Physics** (incomplete)
- ⏳ **Lectures on Electrodynamics** (incomplete)
- ⏳ **Lectures on Quantum Mechanics** (incomplete)

*Note: Courses marked as "complete" are in what I consider a finished state, though improvements are always possible. Those marked as "incomplete" are still under development and may be missing sections or chapters.*

## Repository structure

Each course has its own folder, named similarly to the list above. Inside each folder you will find:

- A main LaTeX file (e.g., `main.tex` or the course name).
- Additional `.tex` files for chapters or sections.
- A `figures/` folder containing images in **PDF** and **SVG** formats.

The SVG files are the editable source (created with Inkscape), while the PDFs are the ones directly included in the LaTeX documents.
